# **🗳️ Digital Voting System - Tinkercad Simulation**  


## **📌 Project Overview**  
This **interactive digital voting system** is simulated in Tinkercad using virtual Arduino components. It demonstrates:  
- Secure voter authentication  
- Real-time vote counting  
- Prevention of duplicate voting  
- Instant result display  

Perfect for **educational purposes, prototyping, or understanding electronic voting systems** without needing physical hardware.  

---

## **🖥️ Main Components**  
The simulation uses these virtual components:  
- **Arduino UNO R3** - The main controller  
- **16x2 LCD Display** - Shows voting instructions and results  
- **Small BreadBoard** - For connection   
- **LED Indicators** - Green (success) and Red (error)  
- **Push Buttons** - For user to make the choice 
---

## **🚀 How to Run the Simulation**  

### **Step 1: Access the Simulation**  
1. Click on the Tinkercad Simulation Link 
2. Sign in to your Tinkercad account (or create one if needed)  

### **Step 2: Start Interacting**  
1. Click the **"Start Simulation"** button  
2. Use the virtual keypad to:    
   - Select your **preferred candidate** (1-4)  
3. Click on the push button for the result
 

### **Step 3: View Results**  
- The LCD displays real-time vote counts  
- Reset the system using the push button
